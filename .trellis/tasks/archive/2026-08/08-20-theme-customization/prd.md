# PRD — 设置页新增主题定制:预设下拉+调色盘+自定义主题

## Goal

在设置页新增「主题」tab,让用户基于预设主题("Editorial Paper",即当前默认)定制设计变量(背景、卡片、文字、强调色等全部 10 个颜色变量),通过调色盘(鼠标取色 + 手动输入 RGB/HEX)调色,支持临时预览与持久保存。保存的自定义主题出现在主题下拉列表中,保存后自动启用。

## 用户价值

- 不改代码即可调整应用配色(护眼、深色偏好、个人审美)
- 预览无风险:临时应用、跨路由保持、关闭软件自动恢复,不影响已保存配置
- 保存即用:自定义主题立即可选、可随时切回

## Background(仓库证据)

- 设置页为 tab 结构(`src/routes/settings/+page.svelte:26` `SETTINGS_TABS`: api/prompt/collect/about),新增 `theme` tab = 数组插一行 + 新 `ThemeTab` 组件
- 可定制面 = `src/app.css:3-17` 的 10 个颜色变量(字体栈 `--sans`/`--mono` 不在范围)
- 主题持久化挂 AppConfig KV(`config.rs` + `db.rs` 显式 KV DAO + `bindings.ts` 镜像 + `emptyConfig()`),新字段须 `#[serde(default)]`,旧配置无损升级
- 配置加载入口 `initConfig()`(`src/lib/store.ts:25`,`+layout.svelte` onMount 调用)是启动应用主题的挂点
- 预览 = 运行时改 `document.documentElement` CSS 变量、不落盘,天然满足"跨路由保持、关闭恢复"
- 全库无原生 `<select>`;含行内重命名/删除的下拉需自研组件

## Requirements

### R1 主题 tab 与预设下拉(选中即激活)
- 设置页二级 tab 新增「主题」(collect 与 about 之间)
- 下拉列出:预设 "Editorial Paper"(标注"预设",不可改删)+ 用户保存的自定义主题
- **下拉选中任一主题 = 立即切换激活并持久化**(重启仍是它),同时载入编辑器供继续修改;预览状态下选中其他主题则预览结束
- 默认(无任何配置)= Editorial Paper

### R2 颜色定制 + 调色盘
- 展示全部 10 个颜色变量,按语义分组(页面/文字/线条/强调/状态),每项含用途说明(如"正文文字、主按钮底色")
- 每项:色块 + HEX 显示 + 打开调色盘 + 单项重置(回所选主题基线)
- 调色盘:SV 取色面 + 色相条(鼠标/指针拖动取色),并支持手动输入 RGB(0-255,失焦钳制)与 HEX,双向同步

### R3 预览
- 「预览」按钮将当前编辑值临时应用到全局(仅内存,不落盘)
- 预览跨路由保持(切日报/周报/历史不恢复),关闭软件才自动恢复
- 预览中显示横幅提示 + 「结束预览」按钮,一键回到已保存激活主题

### R4 保存(全自动命名 + 下拉内管理)
- 「保存」将当前编辑值存为**新**自定义主题:自动命名"自定义主题 N"(N = 未占用最小正整数),立即启用(写配置),下拉新增该项;基于自定义主题修改后再保存也是新建,不做覆盖
- 下拉自定义主题项:悬停 ✎ 重命名(行内输入;空名保持原名,重名自动加后缀)、🗑 删除
- 删除当前激活主题 → 回落 Editorial Paper 并持久化

### R5 编辑现场保持
- 未保存的调色现场(draft)在切换设置 tab / 离开设置页再回来时保留(与报告页状态保留行为一致)

## Acceptance Criteria

- [ ] 设置页出现「主题」tab;下拉含 "Editorial Paper · 预设" 与已保存主题;首次使用无自定义主题、编辑器载入预设值
- [ ] 下拉选中任一主题:全局配色立即切换;重启应用后仍为该主题
- [ ] 修改颜色 → 预览 → 全局即时变化;切换日报/周报/历史页保持;点「结束预览」回到激活主题;重启应用后回到激活主题(预览不落盘)
- [ ] 调色盘可鼠标拖动取色(SV + 色相),可键入 RGB/HEX,双向同步,越界钳制
- [ ] 保存 → 出现"自定义主题 N"并立即启用;重启仍激活;连续保存产生自增不重名的新主题
- [ ] 重命名/删除自定义主题即时持久化;空名保持原名;重名自动后缀;删除激活主题后回落预设;预设不可改删
- [ ] 旧配置(无主题字段)加载不报错,行为等同 Editorial Paper
- [ ] `pnpm check`(0 警告)与 `cargo test` 通过

## Out of Scope

- 字体(--sans/--mono)定制、主题导入/导出、预设主题库扩充(仅 Editorial Paper)
- 覆盖式更新已有自定义主题(保存总是新建)、亮/暗双模式联动
- 重命名/删除的撤销(undo)

## Key Decisions

- 命名方式:全自动命名 + 下拉内重命名(用户选定)
- 下拉语义:选中即切换激活并持久化(用户选定)
- 保存语义:总是新建主题;预设不可变
- 技术方案(含状态三层归属、数据契约、组件拆分)见 design.md
